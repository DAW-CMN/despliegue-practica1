DESPLIEGUE DE APLICACIONES WEB - PRACTICA 1
Cristian Moresi Nadal - 2º DAW SEMI

API REST desarrollada con Node.js, Express y Mongoose.
Base de datos MongoDB Atlas: eventos.

EJECUCION EN LOCAL
1. Instalar Node.js y npm. Proyecto comprobado con Node.js 24.
2. Desde la carpeta del proyecto ejecutar: npm ci
3. Copiar .env.example a .env.
4. Configurar PORT y MONGODB_URI con los datos de la base de datos.
5. Ejecutar: npm start

Otros comandos:
- npm run dev: arranque con reinicio al modificar los archivos.
- npm run seed: carga inicial con los datos de prueba facilitados por el profesor.
  La carga solo se permite cuando las dos colecciones estan vacias.
  La base de datos de la practica ya contiene los datos de prueba.

ESTRUCTURA
- index.js: conexion a MongoDB y arranque de Express.
- models/evento.js: eventos y subdocumentos de entradas.
- models/recinto.js: recintos.
- routes/eventos.js: operaciones de eventos y entradas.
- routes/recintos.js: operaciones de recintos.
- db_seed.js: carga inicial de datos.

RUTAS
GET    /recintos
GET    /recintos/:id
GET    /recintos/localidad/:nombre
POST   /recintos
DELETE /recintos/:id
GET    /eventos
GET    /eventos/:id
GET    /eventos/localidad/:nombre
POST   /eventos
PUT    /eventos/:id
DELETE /eventos/:id
GET    /eventos/entradas/:idEvento/:tipoEntrada
PUT    /eventos/entradas/:idEvento/:tipoEntrada/:cantidad

Enviar los cuerpos de POST y PUT de eventos como JSON con
Content-Type: application/json. La actualizacion de entradas recibe
todos los parametros en la ruta y no necesita cuerpo.

Las respuestas usan ok y resultado, o bien ok y error.
Los codigos HTTP y mensajes corresponden al enunciado de la practica.

DESPLIEGUE EN RENDER
- Tipo: Web Service, plan Free.
- Instalacion: npm ci
- Arranque: npm start
- Variable MONGODB_URI: configurar en el panel con la conexion de Atlas.
- PORT: usar el puerto proporcionado por Render.
- Autorizar en Atlas las direcciones de salida del servicio Render.

El archivo .env real se conserva en el entorno local y no se incluye
en el comprimido de entrega. .env.example documenta las variables.
node_modules tampoco se incluye: npm ci instala las dependencias
con las versiones fijadas en package-lock.json.
